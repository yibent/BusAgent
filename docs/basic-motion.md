# 基础运动与真实执行反馈

所有动作走指令理解、参数补全、计划、校验、执行协调、设备适配器链。普通对话不接收原始操作请求；“正在执行”来自控制器 started 状态，“完成”来自实测关节到位。每条新指令使用独立 task_id，重复投递同一 command_id 不会重复运动。

支持的示例：

| 指令 | 行为 |
| --- | --- |
| 底座顺时针转30度 | 从世界Z轴正方向向下看，底座顺时针转动 |
| 第二关节转到负20度 | shoulder_lift 绝对角度；关节正负方向按 URDF |
| 手腕逆时针转15度 | wrist_roll 相对转动 |
| 末端沿X轴负方向移动1厘米 | 世界坐标下相对平移 |
| 向上移动2厘米 | 世界Z轴正方向；前后=X，左右=Y |
| 移动到X0.3，Y0.1，Z1.3米 | 世界坐标绝对位置 |
| 末端绕工具Z轴顺时针转10度 | 保持末端位置，工具坐标姿态旋转 |
| 归位 | 平滑回到配置初始关节角度，不瞬移 |
| 打开夹爪 / 闭合夹爪 / 夹爪开度百分之五十 | 仅开合，不代表抓取成功；也支持50%写法 |
| 速度每秒20度 | 后续有限运动的关节速度；不改变视觉跟随 RMPflow 参数 |
| 停一下 / 暂停 / 继续执行 | 保持实测位置；继续暂停动作的剩余目标 |
| 停止 / 取消 | 保持实测位置，丢弃剩余动作，不可继续 |
| 开始跟随 / 跟踪电钻 | 开启现有视觉跟随 |
| 查询状态 / 查询能力 | 查询真实控制器数据 |

多轮参数补全保留120秒，例如“旋转九十度”→“绕Z轴”→“顺时针”。末端旋转默认世界坐标，顺时针定义为从轴正方向看向原点。笛卡尔移动只约束位置，不保证维持原姿态或走直线；当前使用 URDF 数值 IK 和关节插值，不是避障规划。SO-101 为五轴臂，完整末端位姿可能无解；无解和关节越界在运动前拒绝。动作超时、仿真暂停、被中断均不能报告完成。

抓取规划、物体抓取、搬运和放置尚未实现。基础夹爪开合不自动升级为这些能力。

HTTP：POST /api/command 返回 accepted 和 command_id；GET /api/commands/{id} 返回 started/completed/failed/cancelled。状态包含实测角度、基于实测角度与URDF推算的末端位姿。HTTP线程只入队，仿真主线程执行驱动。普通运动同一时刻只执行一个，忙时返回 BUSY；HOLD/STOP 可以抢占。适配器轮询运动结果时释放总线投递队列，保持语音中断可用。网络断开记为结果未知，不自动重发。

GPUFree GUI 启动（项目根目录）：

```bash
bash scripts/run_isaac_gui.sh --prompt "power drill" --slow-interval 0
```

该脚本复用桌面所需运行库和模型缓存。启动前应确认7861端口未被另一实例占用。

## 实测与回归

2026-09-05 在 GPUFree 的 Isaac Sim 6.0.1 GUI 上验证了关节相对/绝对运动、夹爪、平移、工具轴旋转、归位、调速、暂停/续执行、停止后不可续执行以及不可达姿态拒绝。WebSocket 通道验证了同会话连续重复动作和三轮旋转参数补全。测试完成后机械臂归位并保持。

以下脚本会实际移动仿真机械臂，仅在需要重跑测试时手动运行：

- `python3 scripts/verify_motion_runtime.py`：控制器动作与实测到位检查。
- 在 `BusAgent/backend` 中运行 `node scripts/check-live-motion.mjs`：前端同协议的文字指令全链路。
- `python3 scripts/verify_voice_interrupt.py`：注入模拟 ASR 事件，验证中断优先通道及重复暂停。此次两次中断从注入到控制器保持约0.11秒，不包含麦克风采集和语音识别耗时。
