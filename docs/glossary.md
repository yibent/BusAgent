# 术语表

| 术语 | 定义 |
| --- | --- |
| BusAgent | 本项目及其总线式多智能体架构。 |
| 消息总线 | 负责消息身份、路由、投递、顺序、背压与观测的逻辑层。 |
| 节点 | 具备稳定身份、明确能力契约和独立生命周期的处理单元。 |
| Agent 节点 | 使用模型进行语义理解、规划或开放判断的节点。 |
| 确定性节点 | 基于明确算法或状态机给出可重复结果的节点。 |
| 入口指令 | 用户或系统发起的一次顶层意图。 |
| 派生消息 | 节点处理消息后产生、并保留因果关联的新消息。 |
| 下一跳 | 当前节点建议消息接下来前往的节点、主题或能力。 |
| 顺序作用域 | 需要保证消息次序的有限范围，例如流、任务、会话或资源。 |
| 流 | 可以在完整结果产生前逐段交付的一组有序消息。 |
| 分片 | 流中的一个增量内容单元。 |
| 提交 | 声明某段流式内容已经稳定、可由下游产生不可逆副作用。 |
| 任务版本 | 任务计划或状态的版本，用于拒绝过期结果。 |
| 执行凭证 | 允许执行特定副作用动作的受控授权，绑定任务和状态。 |
| 能力注册表 | 描述节点支持的输入、输出、版本、并发和权限的目录。 |
| 上下文分块 | 可独立引用、版本化、授权和过期的一组上下文信息。 |
| 上下文装配 | 按消息引用、节点权限和预算构建实际节点输入的过程。 |
| 监督节点 | 检查路由、权限、风险和策略的专职节点。 |
| 背压 | 下游容量不足时向上游传递减速、等待或拒绝信号的机制。 |
| 幂等 | 同一请求重复处理不会产生额外业务副作用的性质。 |
| trace | 关联一次入口指令下所有消息、节点处理和结果的观测轨迹。 |
| ADR | Architecture Decision Record，记录重要架构选择及其理由。 |
